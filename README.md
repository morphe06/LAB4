## Состав решения
- **WPF_PLINQ**: окно с полями размера массива и диапазона, выбором запроса и переключателем LINQ/PLINQ.
- **WPF_PLINQ.Tests**: тесты xUnit на классы поиска и `Digits` (9 штук).

## Что сделано в лабораторной 4
- `INumberSearch`: интерфейс, 4 метода поиска (четные, нечетные, первая + последняя цифра = 6, 666 подряд), ответ отсортирован.
- `LinqSearch` и `PlinqSearch`: реализации интерфейса, во второй перед `Where` стоит `AsParallel()`.
- `Digits`: цифры числа делением и остатком, без перевода в строку, знак числа отбрасывается.
- `ArrayGenerator`: случайный массив через `Enumerable.Range` и `Random.Next`.
- Время запроса меряется `Stopwatch` вместе с `OrderBy` и `ToArray`, кнопка сравнения выводит отношение tLINQ / tPLINQ по каждому запросу.
- Поиск и тесты делались в ветке `lab4-search`, потом слиты в `main` с `--no-ff`.

## Как прогнать тесты
В Visual Studio открыть меню Тест, там Обозреватель тестов и кнопка запуска всех. Без студии хватит `dotnet test` в папке, где лежит .sln.
